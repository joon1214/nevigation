# 충주대원고등학교 3D 배치도

교내에 게시된 **비상대피도**를 읽어 만든 웹 3D 캠퍼스 모델입니다.
건물·층·교실이 실제 도면의 칸 비율대로 배치되어 있고, 두 지점을 고르면
최단 경로를 찾아 3D 공간에 그려 줍니다.

브라우저에서 `index.html`을 열기만 하면 됩니다. 빌드 과정은 없습니다.
(three.js를 CDN에서 불러오므로 인터넷 연결이 필요합니다.)

---

## 담긴 것

**건물 6동**

| | 건물 | 층수 | 주요 공간 |
|---|---|---|---|
| 1 | 본관 | 4층 | 1~3학년 교실 24실, 교무·행정실, 학년별 연구실, 학습카페, 꿈다락 |
| 2 | 별관 | 4층 | 과학·음악·미술·컴퓨터실, 진로활동실, 대원루트, 공용교실 |
| 3 | 후관 | 3층 | 급식실(조리실·학생식당), 정독실, 상담실, 기숙사 |
| 4 | 도서관 | 2층 | 도서관, 창의융합실, 기자재보관실, 문서고 |
| 5 | 담곡관 | 1층 | 예체능교육실, 악기실 |
| 6 | 문화관 | 1층 | 체육관 |

연결복도(3층) 2개, 아고라(2.5층), 운동장, 농구코트, 주차장, 정문·후문까지
부지 시설도 함께 배치했습니다.

**기능**

- 마우스로 회전·확대·이동
- 본관 층 선택 — 고른 층만 또렷하게 남고 나머지 층·다른 건물은 반투명해짐
- 건물별 카메라 이동
- 시설 상자를 클릭하면 이름·층이 나오고, 바로 출발지/도착지로 넣을 수 있음
- 출발지·도착지를 입력하면 길찾기 (자동완성 지원, `3-1`처럼 짧게 입력해도 검색됨)
- 경로 표시 중에는 건물이 반투명해져 어느 층을 지나는지 보임
- 총 이동거리와 구간별 안내 표시

**보이는 방식**

건물·부지를 흰 종이 모형처럼 칠하고 상자의 외곽선으로 형태를 읽게 합니다.
색은 방의 종류(교실 · 복도 · 계단 · 엘리베이터 · 화장실)만 구분하고, 강조가
필요한 곳(선택한 칸, 경로)에만 파란색을 씁니다. 건물 배치와 칸 비율은 비상대피도
그대로이며, 바뀐 것은 색·조명·UI뿐입니다.

## 길찾기가 동작하는 방식

경로 데이터를 따로 만들지 않고, 건물 정의에서 그래프를 **자동으로** 만듭니다.

1. 교실 한 칸이 노드 하나가 됩니다.
2. 같은 건물 같은 층은 복도 순서대로 이웃끼리 연결합니다.
3. 계단·승강기는 위아래 층의 같은 위치끼리 잇되, 수직 이동에 2.4배 가중치를 줍니다.
   본관 중앙 계단과 승강기는 중앙현관 위로 1~4층을 관통하는 별도 탑입니다.
4. 지도에 계단이 표기되지 않은 건물(도서관 등)은 위아래 층에서 가장 가까운 칸을
   이어 내부 계단으로 간주합니다.
5. 연결복도·아고라가 건물 사이를, 야외 보행로망이 건물 출입구를 잇습니다.
6. 다익스트라로 최단 경로를 계산합니다.

기숙사는 생활 공간이라 통행로가 아닙니다. 노드를 지우면 목적지로 고를 수 없게
되므로, 대신 인접 간선에 30배 가중치를 매겨 **출발지나 도착지일 때만** 경로에
포함되도록 했습니다.

표시되는 "총 이동거리"는 탐색 비용이 아니라 경로의 실제 기하 거리입니다
(계단·기숙사 가중치가 거리에 섞이지 않도록 따로 계산합니다).

## 교실을 고치려면

모든 배치는 `index.html` 안의 선언적 데이터입니다. 예를 들어 본관 3층은:

```js
{ cells: [
  { n:'화장실', w:0.50, c:C.wc },
  { n:'1-1',    w:1.20, c:C.g1 },
  { n:'계단',   w:0.45, c:C.stair },
  ...
] }
```

`n`은 이름, `w`는 상대 폭, `c`는 색입니다. `C.*`는 방의 종류를 가리키는 이름일
뿐이고 실제 색은 `TONE`(교실·복도·계단·엘리베이터·화장실)에서 한꺼번에 정해지므로,
배색을 바꾸고 싶으면 셀을 건드리지 말고 `TONE`만 고치면 됩니다.
**`w`의 합은 자동으로 정규화**되므로
방을 추가하거나 빼도 건물 전체 크기는 변하지 않습니다. 여러 층에서 같은 열을
맞추고 싶으면 앞쪽 `w` 값들의 누적 합을 같게 두면 됩니다 — 본관이 이 방식으로
중앙현관과 각 학년 연구실을, 그리고 좌·우 계단을 층마다 정렬하고 있습니다.

건물 밖으로 튀어나온 부분(본관 북쪽 화장실 띠, 별관 화장실, 중앙 계단·승강기탑)은
`annex()`로 따로 붙입니다. 중앙 계단탑의 x는 좌표를 적어 넣은 게 아니라 중앙현관
셀의 실제 위치를 읽어 오므로, 본관 칸 비율을 바꾸면 계단도 따라 움직입니다.

## 한계

- 비상대피도는 **실측 도면이 아닙니다.** 칸의 상대 비율은 최대한 맞췄지만
  실제 치수·면적과는 다릅니다.
- 층고는 모든 건물에서 동일하게 가정했습니다.
- 건물 외곽의 세부 형상(계단실 돌출, 필로티 등)은 단순화했습니다.
- 길찾기 거리는 노드 사이의 직선 거리 합이며, 실제 보행 동선과는 차이가 있습니다.
